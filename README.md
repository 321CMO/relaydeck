# RelayDeck

面向个人和朋友使用的多服务器代理管理面板，目标是简化 VPS 部署、节点创建、内网落地与订阅交付。

**当前处于设计阶段，没有可安装的正式版本。** 已有功能规格与离线流程模型；面板、Agent、安装器和真实 VPS/客户端联调尚待实现。请等待经过验收的 Release 后再安装。

## 规划功能

- 一个中心面板管理多台 VPS，每台可以创建多个对外节点。
- VLESS Reality、Hysteria 2（连续端口跳跃）、SS2022。
- 每位用户独立认证，一个订阅地址聚合全部授权节点。
- 适配 Clash Verge 与 Shadowrocket，提供分流、DNS 与策略组。
- 通过云厂商原生内网建立“入口 A → 落地 B”线路，以向导完成配置。
- 一键脚本和中文菜单，覆盖安装、升级、回退、诊断、备份恢复和卸载。
- 配置版本、任务回执、流量统计、可选额度与到期管理。

## 实现方向

优先验证 sing-box 统一核心，计划采用 Go 后端与 Agent、React/TypeScript 前端、SQLite、systemd 和 Caddy。

## 开发与验收

后续功能使用开发分支与 PR 交付；正式发布通过 GitHub Releases 提供预编译包、安装入口、校验清单和兼容矩阵。

一台测试 VPS 用于安装、升级、恢复和卸载验收；A→B 原生内网落地需要两台互通的 VPS 验证。协议和订阅兼容性还需在实际 Clash Verge 与 Shadowrocket 上测试。

开源许可证将在代码发布前确定。
