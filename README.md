# RelayDeck

为自己和朋友使用的多 VPS 节点管理面板。一个中心管理服务器、节点与用户，每位朋友一个固定聚合订阅地址。

**当前为 `0.1.0-alpha.1` 开发预览，尚未发布经过 VPS 验收的安装版本。** 设计文档定义完整第一版；下面列出当前实际实现，避免把规划当成已完成。公开源代码的许可证尚待确定，没有复制 3x-ui 源码。

## 已实现的开发功能

- Go 中心与 Agent、React/TypeScript 中文界面，六个页面、四步交付、桌面/移动布局及深色模式。
- 首次设置码、管理员登录、Argon2id 密码、会话撤销、CSRF/来源检查和登录失败限制。
- 加密 SQLite 数据、独立本机主密钥、单实例锁；用独立口令加密的可移机备份与终端恢复。
- 多服务器登记、一次性注册码绑定设备、Agent 身份与 HTTPS 同步。
- VLESS Reality + Vision、HY2、SS2022 配置编译；按朋友生成独立凭据。
- 配置任务与目标/生效版本；Agent 先检查核心配置，应用失败尝试恢复旧核心；待应用授权不进入订阅。
- 聚合订阅与交付页；Clash Verge 完整 Mihomo 配置（DNS、策略组、分流、HY2 连续跳跃）；Shadowrocket 节点 URI 订阅。
- 选择入口节点的内网落地机，生成独立内部 SS2022 链路；只使用 B 内网地址，无自动入口直出回退；独立内网源 IP 防火墙。
- Linux 专用 nftables 表管理 HY2 UDP 重定向；不清空已有防火墙。
- 启用/停用与到期、Agent 本机到期处理；20 分钟中心授权租期，长时间失联停止核心。
- 客户端与服务端域名/IP 规则。服务端例外直连规则优先于落地出口，内部入站固定直出以避免成环。
- TG Bot 验证、手动 Chat ID 测试发送、管理员离线/恢复/配置失败/到期通知、每日摘要与持久队列重试。
- 面板 HTTPS 配置生成、证书导入校验、Caddy 校验与加载、正常 CA 验证的对外访问探测。只有域名 TLS 和当前实例都验证成功才标记已验证。
- 开发安装器、管理命令、GitHub CI；Linux amd64/arm64 编译目标。

## 本机开发

需要 Go 1.27.2、Node.js 24；依赖锁定在 go.sum 与 package-lock.json。

```sh
npm ci
npm run build
go build -o ./bin/relaydeck ./cmd/relaydeck
./bin/relaydeck serve --dev --data ./local/panel --url http://127.0.0.1:8787
```

读取 `local/panel/bootstrap.txt` 中的设置码，在 `http://127.0.0.1:8787` 创建管理员（密码至少 12 位）。没有预置管理员、服务器、节点或示例朋友。生产中心只监听本机回环地址，由 Caddy 提供外部 HTTPS。

改前端可单独运行 `npm run dev`；开发代理仍连接 8787，`--dev` 仅允许本机 HTTP。
