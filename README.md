# RelayDeck

为自己和朋友使用的多 VPS 节点管理面板。一个中心管理服务器、节点与用户，每位朋友一个固定聚合订阅地址。

**当前为 `0.1.0-alpha.9` 开发预览，正在补齐生产可靠性，尚未发布商用稳定安装版本。** 已完成两台 amd64 云 VPS 的原生内网 A→B 三协议、出口与故障阻断验证，结果见 [实际验收记录](docs/真实VPS验收.md)。设计文档定义完整第一版；下面列出当前实际实现，避免把规划当成已完成。RelayDeck 自身代码采用 [MIT](LICENSE)，随包核心保留上游许可和构建材料，见 [第三方声明](THIRD-PARTY-NOTICES.txt)；没有复制 3x-ui 源码。

设计方向已调整为面向 3x-ui 老用户：完整节点参数、出站一键导入、原生配置与批量操作的新增要求见 [v9 功能规格](docs/3x-ui老用户功能规格.md)。alpha.5 已完成首批分享链接导入和三协议参数扩展，其余新增能力仍待实现；下面只记录实际功能。

体验复查及修复状态见 [待完善清单](docs/体验复查与待完善清单.md)。alpha.6 修正通知、导入预览、并发保存、刷新失败重试与表单等问题；功能缺口继续单独跟踪。

生产差距与关闭条件见 [商用就绪审查](docs/商用就绪审查.md)。alpha.7 修复反向代理下的登录限流隔离，升级面板依赖，按明确安全依赖覆写重建 sing-box/Caddy，新增不停机加密备份与独立校验。详见 [安全构建与漏洞处置](docs/安全构建与漏洞处置.md)；这轮加固不代表所有商用门槛已通过。

## 已实现的开发功能

- Go 中心与 Agent、React/TypeScript 中文界面，六个页面、四步交付、桌面/移动布局及深色模式。
- 首次设置码、管理员登录、Argon2id 密码、后台修改密码、会话撤销、CSRF/来源检查和登录失败限制。改密验证当前密码，成功后退出所有会话。
- 加密 SQLite 数据、独立本机主密钥、单实例锁；用独立口令加密的可移机备份与终端恢复、不停机只读快照导出、备份独立校验和私有口令文件支持；后台导入先预览影响，确认后恢复业务配置，保留当前管理员和 HTTPS 入口，自动保留最多 3 份同机恢复点。
- 多服务器登记、一次性注册码绑定设备、未绑定安装码重发、Agent 身份与 HTTPS 同步。
- VLESS Reality + Vision、HY2、SS2022 配置编译；按朋友生成独立凭据。
- 配置任务与目标/生效版本；Agent 先检查核心配置，应用失败尝试恢复旧核心；待应用授权不进入订阅。
- 同一固定地址支持客户端订阅和朋友个人网页，显示本人用量、到期、授权节点与状态；Clash Verge 的 Mihomo 配置（DNS、策略组、分流、HY2 连续跳跃）；Shadowrocket 节点 URI 订阅。
- 管理入口默认使用独立随机 HTTPS 端口和 192 位随机安全路径，默认域名与端口根路径返回 404；网页支持自定义 6–96 位安全路径或重新随机生成，切换失败保留原入口，朋友订阅与 Agent 地址保持有效。
- 用户 TCP/UDP 上传下载统计、本机持久累计、中心按来源与用户高水位去重；未知或部分缺失数据明确标注，客户端订阅响应附带用量和个人网页地址。
- 选择入口节点的内网落地机，生成独立内部 SS2022 链路；只使用 B 内网地址，无自动入口直出回退；独立内网源 IP 防火墙。
- Linux 专用 nftables 表管理 HY2 UDP 重定向；不清空已有防火墙。
- 启用/停用与到期、Agent 本机到期处理；20 分钟中心授权租期，长时间失联停止核心。
- 分流按服务器管理「路由规则 / 出站 / 客户端分流」。规则支持排序、开关、复制、域名/IP/端口/来源/网络/协议/入站节点/订阅条件，以及直连、拒绝和指定出口；支持 geosite/geoip 远程规则集。
- 自定义 SOCKS5、HTTP/HTTPS、VLESS Reality、HY2（可端口跳跃）、SS2022 出站及链式代理；默认出口、嗅探和域名解析可配置。系统内网落地出站自动展示，管理端口保护和内部入站直出始终优先；提供脱敏配置预览。
- 订阅安全工作台可单独重置地址或指定节点认证，预览影响、确认执行、旧凭据撤销、应用前交付门槛和幂等重试；最近 2000 条审计只记录对象及字段名，不记录密码、密钥或订阅地址。
- TG Bot 验证、手动 Chat ID 测试发送、管理员离线/恢复/配置失败/到期通知、每日摘要与持久队列重试。
- 出站单条/多行链接、Base64 URI 集合和文本文件导入，逐项预览、去重、覆盖保留稳定引用；分享链接复制、单个下载与全量链接导出。未知协议参数明确失败。
- 入站分区配置，监听/对外地址与端口、Tag、默认/明确直连/指定出站/内网落地；Reality Flow/指纹/密钥/多个 Short ID/最大时间差，HY2 Salamander/带宽/伪装/ALPN，SS2022 AES-128/256 与显式密钥轮换。参数参与核心编译与订阅导出。
- 面板 HTTPS 配置生成、证书导入校验、Caddy 校验与加载、正常 CA 验证的对外访问探测。只有域名 TLS 和当前实例都验证成功才标记已验证；新交付链接采用验证过的订阅域名，短时探测失败不改地址。
- 成功提示约 3 秒自动关闭；未保存改动提醒、独立设置分区与版本冲突检查、创建操作幂等回执、刷新失败与旧数据提示、诊断任务、交付就绪数量和删除影响预览。
- 开发安装器、管理命令、GitHub CI；Linux amd64/arm64 编译目标。
- 旧备份恢复采用新代次重新同步 Agent，重新确认应用前不交付恢复的授权；已保留身份的 Agent 支持无安装码重装。

## 本机开发

需要 Go 1.27.2、Node.js 24；依赖锁定在 go.sum 与 package-lock.json。

```sh
npm ci
npm run build
go build -o ./bin/relaydeck ./cmd/relaydeck
./bin/relaydeck serve --dev --data ./local/panel --url http://127.0.0.1:8787
```

读取 `local/panel/bootstrap.txt` 中的设置码，在 `http://127.0.0.1:8787` 创建管理员（密码至少 8 位）。没有预置管理员、服务器、节点或示例朋友。生产中心只监听本机回环地址，由 Caddy 提供外部 HTTPS。

改前端可单独运行 `npm run dev`；开发代理仍连接 8787，`--dev` 仅允许本机 HTTP。

## 内部检查

```sh
go test -race ./...
go vet ./...
npm test
npm run build
bash -n scripts/relaydeck.sh
python3 scripts/build-installer.py
```

核心测试没有对应二进制时会明确跳过；CI 校验 sing-box v1.14.3 与 Caddy v2.11.7 的官方源码模块摘要，按显式安全依赖覆写重建两个核心，执行实际标签/目标的源码漏洞扫描、配置解析及真实 TCP/UDP 测试，并保留构建材料。三个协议均已在本机用两位独立用户验证连接，未知凭据被拒绝；内网转发逻辑用本机进程验证落地停止后 TCP/UDP 不会直出回退。云 VPS 原生内网结果仍以实机记录为准。

本机浏览器测试共 64 项，包含订阅、路由排序/引用保护、出站导入与编辑、入站参数、配置预览、账号改密、安全路径表单与移动端操作；Agent 回执由测试端发送；另外在真实 VPS 上以真实 Agent 和公开 CA 证书运行 11 项基础浏览器检查及 11 项路由/出站操作。官方 sing-box 与 Mihomo v1.19.32 连接实际订阅的三协议 TCP/UDP、HY2 跳跃通过，详见 [单 VPS 验收记录](docs/真实VPS验收.md)。旧 simulation 目录只是设计模型。
