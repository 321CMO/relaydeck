日期：2026-10-17。实施版本：`0.1.0-alpha.8`。面向熟悉 3x-ui 的单管理员、多 VPS、聚合订阅工作流；底层仍为固定版本 sing-box，不把 Xray 专有字段直接套入。

## 本轮结论

**配置便利性与误操作保护已补强，仍不能宣布可以直接商业运营。** 参数生成、核心配置检查、从入口检测目标和客户端真实连通是不同检查层次；任何一层通过，都不能替代长期可用性和恢复能力。完整上线门槛继续见 [商用就绪审查](商用就绪审查.md)。

## 已处理的节点问题

| 编号 | 发现或核对 | alpha.8 行为 |
| --- | --- | --- |
| NODE-01 | Reality 只有一个硬编码目标，缺少选择与入口侧检测 | 提供 Microsoft、Apple、Amazon AWS 候选，选择时同步 SNI/目标；支持手填。在线 Agent 从对应 VPS 检测 DNS、公网地址、TCP、TLS 1.3、X25519、SNI 证书和 h2；分别呈现成功、失败与超时 |
| NODE-02 | 重新生成 Short ID 可能被旧 Short ID 列表覆盖 | 生成结果同步单值和列表。另设“追加随机 Short ID”，保留旧值及订阅使用的首项 |
| NODE-03 | 参数格式与随机长度不够直观，HY2 混淆需手写 | 明示并生成 X25519、16 位随机十六进制 Short ID、SS2022 按算法生成主密钥、32 字节随机 HY2 混淆值。用户认证 UUID/密码/客户端密钥仍按订阅独立自动生成 |
| NODE-04 | 查看已保存密钥会填入草稿，可能引发误轮换及脏状态 | 只读临时查看，30 秒隐藏、可立即隐藏，不写入编辑字段 |
| NODE-05 | Reality 私钥轮换缺少明确确认 | 已有节点更换私钥须确认；服务端也拒绝未确认轮换，界面提示受影响订阅与刷新要求 |
| NODE-06 | 切换协议残留旧目标、密钥、证书、混淆和跳跃值 | 新建表单切换协议时清空协议专属值并重建默认配置；已有节点协议/服务器保持不可变，使用新建流程 |
| NODE-07 | 默认 TCP 443 易与共机 Caddy 冲突，没有按已知节点推荐 | Reality 首选 18443；根据服务器、TCP/UDP、SS 网络类型及 HY2 跳跃范围跳过已知占用与保留端口。推荐值不等于操作系统端口探测结果 |
| NODE-08 | SS 网络限制未参与冲突判定；跳跃校验上下限不完整 | TCP/UDP 按实际网络独立判定；同网络冲突仍拒绝。跳跃间隔 5–3600 秒、最多 4096 连续端口、拒绝保留端口及额外端口映射组合；该范围限制是面板运维策略，不是协议规定 |
| NODE-09 | 旧列表全空编辑可能删掉其他接受的 Short ID，重复/空白值不明确 | 去除空白行、统一小写；空输入沿用旧列表；首次空输入生成；拒绝重复及非 2–16 位偶数十六进制输入 |
| NODE-10 | 自定义 ALPN 是否真实生效需核对 | 确认原编译器已写入入站 TLS，新增实际配置回归，未将此项记为原有缺陷；HY2 自定义 ALPN 必须含 h3 或留空 |
| NODE-11 | 异步生成/检测结果可能错用于已改变的表单 | 绑定编辑上下文与请求序号；改变服务器、目标/SNI 后清除结果，旧返回不能显示为当前成功 |
| NODE-12 | 缺少保存前汇总和交付/故障语义 | 四个分区：基本、协议与安全、连接与出口、检查与确认。汇总监听、客户端连接、出口、认证与警示；明确保存后仍需授权及 Agent 应用 |

新增检测不是通用网页代理：只接受正常域名与端口、管理员鉴权及 CSRF、在线绑定 Agent；任务限总量、每台一个、90 秒超时、10 分钟保留。DNS 解析包含非公网或混合地址时拒绝，并固定解析后的地址拨号，避免二次解析访问内网。TLS 使用正常信任链和域名验证，不提供跳过验证。回执必须来自绑定的 Agent；旧 Agent 不支持时以超时呈现，不显示通过。新 Agent 无结果时不发送新增回执字段，方便分步升级。

## 参数选择说明

Reality 的预设只是候选。地区、DNS、目标负载和站点配置变化会影响可用性，须从实际入口检测；不会自动切换到“更快”的目标，以免造成订阅与服务端 SNI 不一致。当前检测不请求网页，因此**不检查重定向、整条代理连接或抗探测效果**。不承诺某个域名长期可用、不可识别或免封。

- X25519 私钥：32 字节密码学随机密钥，43 位无填充 Base64URL；公钥由私钥计算。
- Short ID：默认 8 字节随机值，编码后 16 位十六进制。协议允许更短甚至空值；本面板新配置采用非空值策略，不将其描述为 UUID 的替代品。
- SS2022 AES-128 / AES-256：主密钥分别是 16 / 32 随机字节，标准 Base64 后为 24 / 44 字符。客户端认证另行按订阅生成，不能用普通文本密码代替。
- HY2：订阅认证密码与 Salamander 混淆值不同；开启混淆也不等于 TLS 或网站伪装。带宽 0 保留核心默认行为。证书须匹配自有域名，客户端正常验证证书。
- HY2 自动证书：需要 DNS 和 TCP 80 挑战条件，与中心 Caddy 共机时使用导入证书；导入证书的续期仍需运维负责，尚无自动共享证书能力。
- 端口跳跃：Agent 处理 VPS 本机 UDP 重定向，云安全组需管理员放行完整范围。Clash 导出跳跃参数，Shadowrocket 当前导出固定端口，未宣称客户端全功能对等。

依据：[Reality 上游目标选择说明](https://github.com/XTLS/REALITY/blob/main/README.en.md)、[sing-box TLS 配置](https://sing-box.sagernet.org/configuration/shared/tls/)、[HY2 入站](https://sing-box.sagernet.org/configuration/inbound/hysteria2/)、[Shadowsocks 入站](https://sing-box.sagernet.org/configuration/inbound/shadowsocks/)。实现和测试以项目固定的 sing-box 1.14.3 为准，不采用文档中仅新版本支持的字段。

## 商用前仍需关闭

1. 将真实协议、公网端口、DNS/云安全组诊断纳入发布流程；当前 Reality 目标检测不能代替端到端测试，失败仍允许管理员修正并保存配置。
2. HY2 证书到期/续期、共机共享或分发证书、失效告警；当前导入证书生命周期不够自动化。
3. 订阅 URL 泄露后的 token 与各节点认证分别轮换、旧认证撤销和客户端重导入流程；本轮仅完善共享节点密钥轮换，未补完整使用者凭据工作台。
4. 节点、订阅及路由的完整并发版本冲突保护、发布影响/配置差异和关键操作审计；当前部分设置已有冲突检查，不能外推所有对象。
5. 中心失联租期策略、自动离机备份及全损恢复、长时间容量和故障运行、真实 TG 投递与客户端真机兼容性。
6. 明确支持规模、正式 Release/安装版本、项目许可证和安全维护方式；保持开发预览标识，不能仅以 UI 齐全改称稳定商用。
