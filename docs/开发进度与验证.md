# RelayDeck 开发进度与验证

当前为 0.1.0-alpha.1 开发预览。完整产品范围以功能规划 v8 为准；源代码实现与正式部署验收分开记录。

## 已执行的检查（2026-10-15）

| 检查 | 实际范围 |
| --- | --- |
| Node 检查 21/21 | 13 项安装生命周期故障、5 项程序包校验、3 项界面状态检查 |
| TypeScript / Vite | 代码类型检查与前端构建通过 |
| Go 竞态检查与 vet | 登录/CSRF、加密存储与回退、授权隔离、订阅应用门槛、端口冲突、内网成环、备份、HTTPS 状态、TG 错误脱敏等 |
| 官方 sing-box 配置 | VLESS Reality、HY2 导入/自动证书、SS2022、A→B 内部监听与出口配置均被固定核心接受 |
| 官方核心真实 TCP/UDP | 三种协议，各两位独立用户均能访问本机目标；未知凭据不能访问目标 |
| 落地故障阻断 | 本机 A/B 两个核心进程完成 TCP/UDP 转发；停止 B 后，目标收不到直出回退流量 |
| 官方 Caddy 配置 | 首次安装配置、自动证书、独立订阅域名、导入证书四个场景的配置被实际适配器接受 |
| 浏览器交互 11 项 | 首次设置、空状态、添加服务器/节点/朋友、应用前订阅拒绝、应用后导出、移动端无横向溢出、六页导航、退出与加密备份下载等 |
| 安装器 | Bash 语法、单文件生成、无需权限的帮助命令均通过 |

官方核心分别固定 sing-box v1.14.3 与 Caddy v2.11.7，下载摘要来自上游发布资产。文件与摘要固定在 `scripts/core-artifacts.json`；没有实际核心时对应测试明确跳过。

协议测试只使用本机临时端口和测试凭据。HY2 使用明确加入测试客户端信任的本地证书，Reality 使用本地 TLS 1.3 目标，未把这些测试算作公有 CA 或真实网站部署验收。A→B 测试将地址改为本机回环用于进程联通；没有修改本机内网接口、防火墙或云安全组。

浏览器运行真实 HTTP 服务，Agent 回执由测试端发送。安装生命周期测试执行真实文件复制、版本指针切换、快照恢复和中断记录；systemd 的启动与健康状态使用替身。两者不能代替真实 Agent 与 Linux 安装验收。

## 实际修正

- 修正首次安装的 Caddyfile 语法，加入官方解析器回归检查。
- 首次安装预填 HTTPS 域名，仍需正常 CA 校验和当前实例对外探测才能标记已验证。
- 手机端完整显示六个主入口，并提供退出登录。
- 复制朋友订阅后，交付步骤可记录完成。
- 升级前保留本机私有快照，整体切换程序；失败尝试恢复，中断保留恢复记录；手动程序回退保留用户后续修改。
- 程序包限制固定文件名、普通文件和无重复条目，并保留官方核心的许可证。

没有真实 VPS、实际 Clash Verge/Shadowrocket 或 Bot 的通过记录。正式公开安装入口、云安全组、两台 VPS 原生内网的 TCP/UDP/DNS、实际 ACME 申请/续期、Shadowrocket 分流与跳跃、流量统计与去重、完整 TG 绑定/朋友查询、数据库迁移和节点可移机备份仍需继续完成。现有核心握手和浏览器结果不代表这些项目已完成。
