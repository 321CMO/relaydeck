# RelayDeck 开发进度与验证

本记录区分源代码实现、本机测试与真实部署验证。完整产品范围仍以功能规划 v8 为准。

## 2026-10-15：安装升级可靠性

本轮完成：

- 三个程序由同一版本目录提供，一个指针整体切换，避免逐个覆盖程序时出现混用版本。
- 升级前保存 panel、agent、caddy 的本机私有快照，Agent 单独部署不依赖中心数据库。
- 按升级前状态恢复服务；原本未运行的服务保持停止。
- 内部服务先通过检查，再重新开放 HTTPS。
- 启动失败、运行检查失败时尝试恢复原程序与快照；中断升级保存恢复记录。
- 手动程序回退保留升级后的用户更改；回退失败尝试恢复当前程序。
- 构建单文件安装器，源码库不会变成最终用户的额外安装步骤。
