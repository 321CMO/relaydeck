# RelayDeck 开发进度与验证

当前为 0.1.0-alpha.7 开发预览。完整产品范围以功能规划 v9 与 3x-ui 老用户功能规格为准；源代码实现与正式部署验收分开记录。

alpha.7：修复可信反向代理后的登录限流，加入来源校验、短时预算、非排队密码哈希及请求上限；升级面板 gRPC，并以显式安全依赖覆写重新构建 sing-box/Caddy。新增不停机只读加密快照、私有口令文件、备份独立校验与原子写入。Go race/vet、21 项 Node 检查、48 项本机浏览器及重建核心实际协议测试通过；两台云 VPS 的隔离 A→B、故障阻断、Agent 运维与新主机中心状态恢复结果见 [实机记录](真实VPS验收.md)。正式生产差距继续按 [商用审查](商用就绪审查.md) 跟踪。

官方核心分别固定 sing-box v1.14.3 与 Caddy v2.11.7，下载摘要来自上游发布资产。文件与摘要固定在 `scripts/core-artifacts.json`；没有实际核心时对应测试明确跳过。

协议测试只使用本机临时端口和测试凭据。HY2 使用明确加入测试客户端信任的本地证书，Reality 使用本地 TLS 1.3 目标，未把这些测试算作公有 CA 或真实网站部署验收。A→B 测试将地址改为本机回环用于进程联通；没有修改本机内网接口、防火墙或云安全组。

浏览器运行真实 HTTP 服务，Agent 回执由测试端发送。安装生命周期测试执行真实文件复制、版本指针切换、快照恢复和中断记录；systemd 的启动与健康状态使用替身。两者不能代替真实 Agent 与 Linux 安装验收。

## 实际修正

- 修正首次安装的 Caddyfile 语法，加入官方解析器回归检查。
- 首次安装预填 HTTPS 域名，仍需正常 CA 校验和当前实例对外探测才能标记已验证。
- 导入证书与 DNS 凭据按版本保存为私有文件，校验或重载失败不会覆盖旧配置引用的证书和凭据；新增失败分支回归检查。
- Cloudflare 通过 Caddy 的文件占位符读取凭据，不依赖临时 reload 子进程环境。默认包不含此模块，自定义模块及真实 DNS 申请仍未验收。
- 手机端完整显示六个主入口，并提供退出登录。
- 未登记服务器可重开安装码，旧码失效；已绑定身份不能被重开安装码覆盖。
- 新交付链接采用已验证的独立订阅域名；探测短时失败不改地址，已发布域名暂禁止静默更换。
- 复制朋友订阅后，交付步骤可记录完成。
- 升级前保留本机私有快照，整体切换程序；失败尝试恢复，中断保留恢复记录；手动程序回退保留用户后续修改。
- 程序包限制固定文件名、普通文件和无重复条目，并保留官方核心的许可证。

## alpha.4 新增

- 统一将「朋友与订阅」页面及创建/编辑操作命名为「订阅」。已有订阅名、固定地址和访问凭据保留。
- 按服务器管理路由规则、出站和客户端分流。支持规则排序、开关、复制及多条件匹配；不同条件同时满足，同一条件多项任一满足。
- 新增 SOCKS5、HTTP/HTTPS、Reality、HY2、SS2022 自定义出站、默认出口与防循环代理链；引用存在时禁止删除，活跃引用存在时禁止停用。编辑密码/UUID 留空沿用；状态接口和预览不返回密钥。
- 支持 geosite/geoip 编译为 MetaCubeX 的 sing-box 远程规则集，缓存于 Agent 本机。首次下载仍需要网络，分类必须存在；下载/检查失败不能被误报为已应用。
- 固定官方核心接受新增出站和组合规则配置；实际两核心进程验证订阅范围匹配及 SS2022 出站 TCP/UDP，出口停止后无直出回退，未命中的订阅仍直连。
- 中心路由数据使用 schema 4，旧程序拒绝打开；旧规则按原匹配含义兼容。该设计参考 3x-ui 的基本规则字段和出站组织，独立实现；不包含其全部 Xray 出站、负载均衡、WARP 或原始 JSON 编辑功能。

路由使用说明见 [路由与出站](路由与出站.md)。
