# 开发预览的运维边界

当前开发器支持 Debian/Ubuntu + systemd，amd64/arm64。正式一键命令将在发布包和真实 VPS 验收完成后提供；此文面向开发测试。

## 组件与目录

中心使用 `/var/lib/relaydeck/panel`，Agent 使用 `/var/lib/relaydeck/agent`；二进制在 `/opt/relaydeck/bin`，代理与 HTTPS 核心在 `/opt/relaydeck/core`。同一台 VPS 可同时有中心和 Agent，两者目录与服务分开。

数据目录包含访问凭据。中心数据库加密密钥 `master.key` 必须和数据库一起保留；缺失时中心拒绝生成替代密钥。网页加密备份使用独立口令，可以恢复到新中心；它不包含 Agent 本机 ACME 缓存和证书目录。

中心监听 127.0.0.1:8787。Caddy 监听公网 80/443（证书和公开订阅）以及随机高位管理 TCP 端口；管理网页只在该端口的随机安全路径中提供，域名和端口根路径均返回 404。Caddy 管理 API 仅为本机 2019；不要暴露到云安全组。共机时公开 Reality TCP 443 与 Caddy 冲突，应改用其他端口；关闭 HTTP/3 后 HY2 可使用 UDP 443，自动 ACME 的 TCP 80 与 Caddy 仍有资源冲突，需要导入证书。

Agent 管理的内网链路保留端口为 TCP/UDP 18999；云安全组只允许入口机内网源地址访问。自动 nftables 规则只能约束 VPS 本机，不替用户修改云安全组。A、B 原生内网地址必须由云厂商分配，跨云私网地址不能直接假定可达。

## 开发包与安装

开发包要求三个普通可执行文件：`relaydeck`、`sing-box`、`caddy`，允许附带固定名称的 `CADDY-LICENSE.txt` 和 `SING-BOX-LICENSE.txt`。程序包压成 tar.gz，禁止重复条目、符号链接、额外路径与目录穿越。官方核心版本暂固定 sing-box v1.14.3、Caddy v2.11.7；测试时须核对发布摘要。默认 Caddy 不含 Cloudflare 模块，DNS 验证需要另行构建并验证。

```sh
sudo bash scripts/relaydeck.sh install panel --domain panel.example.com --artifact /path/to/trusted-development-package.tar.gz
sudo bash scripts/relaydeck.sh install agent --endpoint https://panel.example.com --server srv_x --artifact /path/to/trusted-development-package.tar.gz
```

开发包来源由操作人显式确认；发布包下载会要求固定版本并核对 SHA256SUMS。Agent 注册码从标准输入读取，不放在参数中。中心安装时会预填自动 HTTPS 域名，公网 TLS 和当前实例探测成功后才显示已验证。安装后读取首次设置码，15 分钟内创建管理员；添加服务器的注册码有效期 10 分钟，首次成功登记绑定设备，丢失响应可在同一设备重试。

未登记服务器可在服务器列表点击「安装 Agent」重新生成注册码，旧码立即失效；已绑定设备不能重新生成注册码。重装已绑定 Agent 时需先备份本机身份；身份重置与撤销流程仍需继续完善。

独立订阅域名只有完成公网 TLS 与当前实例验证后才用于新交付链接；已经发布的域名不会因短时探测失败而切回面板域名。当前版本禁止修改或清空已发布订阅域名，避免破坏朋友的固定地址；完整域名迁移仍在开发。

## 管理命令

`show-entry` 找回完整管理地址。`access --admin-port 端口 --rotate` 修改端口并重新生成随机路径；网页「设置」也可修改。网页切换成功会跳转新入口重新登录，检查或加载失败保留旧入口。请先放行新 TCP 端口。完整地址保存在 0600 的 `panel/admin-entry.txt`，首次安装自动打印，可用 `--admin-port` 指定端口。

`status` 显示服务；`logs panel|agent` 显示诊断；`setup-code` 重新生成未初始化设置码；`reset-password` 从标准输入重置管理员密码。安装器会在需要独占数据库的操作前停止中心并尝试恢复服务。

后台「设置 → 账号与安全」可修改管理员密码，需要当前密码、新密码和确认密码。新密码为 至少 8 个字符、最多 128 字节，成功后全部已登录设备退出，用户名、订阅和节点认证保持不变。连续 5 次当前密码错误后，该操作限制 15 分钟；忘记当前密码使用终端 `reset-password`。

「设置 → 面板与订阅 HTTPS → 更改管理端口与安全地址」支持手填路径或重新随机生成，展示自定义入口预览。路径为 6–96 个 ASCII 字母、数字、下划线或连字符，首尾斜杠会自动去除，不能包含内部斜杠、空格、查询参数或点号。切换先验证并加载 Caddy，成功后旧入口失效、所有会话撤销并跳转新入口；订阅和 Agent 公共地址不变。找不到入口可在服务器运行 `show-entry`。

`backup 文件` 和 `restore 文件` 使用独立口令；恢复前停止中心。`repair-https` 校验初始 Caddyfile 并重启专用 Caddy 服务；导入证书和 DNS Token 按版本保留在中心数据目录的私有文件中，失败加载不会覆盖旧配置引用的文件。Cloudflare 采用 Caddy 的文件占位符读取 Token，不依赖 reload 命令的临时环境；仍需包含对应模块的 Caddy 构建与真实 DNS 联调。占位符行为见 [Caddy 官方说明](https://caddyserver.com/docs/caddyfile/concepts#environment-variables)。

`uninstall panel|agent` 仅删除对应服务，默认保留数据与程序，不清空其他防火墙表。卸载 Agent 会删除 RelayDeck 专用 nftables 表；在中心同时移除授权。完整数据销毁和云安全组清理由操作人单独处理。

## 当前不作为上线承诺的部分

开发安装器使用不可变的程序包目录，通过一个符号链接一起切换中心、Agent、sing-box 和 Caddy 的程序版本。共机安装第二个角色时不会偷偷更新第一个角色；版本不同时会要求先执行升级。

升级会记录正在运行的服务，先关闭公网 HTTPS 入口，再停止内部服务；创建本机私有快照后切换程序。快照包含已有的 panel、agent、caddy 目录，不要求 Agent 服务器存在中心数据库。目录仅允许 root 访问，属于同机回退快照；需要可移机且带独立口令加密的中心备份时，仍使用网页备份或 `backup` 命令。

新程序通过内部服务运行检查后，才重新打开 HTTPS。启动或运行检查失败时，会尝试恢复原程序和升级前快照；中断时保留恢复记录，下一次管理命令先执行恢复。原先停止的服务不会被升级自动启动。

手动 `rollback panel|agent` 只回退程序，保留升级后用户的修改；旧程序不能运行时会尝试切回当前程序。数据库不兼容时需要显式恢复备份，不会静默覆盖数据。

以上除隔离目录回归外，已在 Debian 13 systemd 实测初装、升级、程序回退、启动失败恢复、加密备份恢复与保留数据重装；磁盘故障和其他系统仍未验收。服务运行检查不能代替真实代理握手；应用回执也不代表云安全组和客户端已通过。通用数据库迁移与完整可移机节点备份仍需完成。

CI 会把 amd64/arm64 开发包与校验清单上传为 `relaydeck-linux-development` 构建产物，保留 14 天；尚未创建正式 GitHub Release。

源码中的脚本会加载同目录的生命周期库。发布前运行 `python3 scripts/build-installer.py` 生成单个 `release/relaydeck.sh`，用户安装时不需要再下载库文件。当前还没有正式发布此安装入口。

程序在 Agent 断开中心 20 分钟后停止核心，以限制停用授权长时间不落地。恢复中心连接后按最新配置重新启动。需要不同失联策略时，先补完租期配置与可视化说明，再改变此默认值。

单 VPS 安装、三个协议与证书联调已通过；alpha.7 已完成两台云厂商原生内网 VPS 的 A→B TCP/UDP、域名访问、出口 IP、落地故障阻断和恢复，见实机记录。客户端图形界面完整矩阵仍待验证。

恢复旧备份会生成新的恢复代次，清零旧应用回执并重发配置，防止较新 Agent 因旧计数拒绝恢复。对应数据使用 schema 2，alpha.1 会拒绝打开；回退到不兼容版本时会尝试返回当前程序。HTTPS 需重新加载验证。多台 VPS 必须先把中心和全部 Agent 升级到 alpha.2 后再使用此恢复流程。

启用安全入口的中心数据升级为 schema 3，alpha.2 及更早程序拒绝打开。恢复后使用备份中的端口与安全路径，请通过 `show-entry` 找回并确认云安全组。

## 用户流量与个人订阅页

朋友只需一个固定订阅地址，客户端读取配置，浏览器查看本人用量与状态。停用或到期仍能查看状态，客户端导出拒绝；页面不依赖管理员会话。

统计核心使用固定、未修改的 sing-box v1.14.3 官方源码，增加 `with_v2ray_api` 构建标签；仅监听回环 10085。`scripts/build-stats-core.py` 校验源码及 go.mod 摘要，CI 产物同时附带对应源码 ZIP、许可证与构建记录。10085 为内部保留端口。

只统计入口的用户代理数据上传与下载，不统计客户端直连流量或内部 backhaul 用户，避免 A→B 重复累计。约 15 秒采样并上报，页面显示采集起始时间和最后上报时间，未知或部分缺失明确标注；旧版本流量无法追补。

保留 Agent 的 `traffic.json` 和身份文件。Agent 持久累计，中心按统计来源和用户保存高水位；重试与中心旧备份恢复按差值追赶。正常重启前尝试最后采样，断电或强杀可能丢失最后未采样数据；额度限制仍禁用。

通过公开节点或内部落地转发时，服务端优先拒绝目的端口 2019、8787、10085，保护本机 Caddy 管理、中心和统计接口，包括使用 DNS 别名的访问。这些端口不作为代理目标开放。程序升级会重新编译并同步已有服务器，Agent 不直接启动旧编译器生成的缓存配置。

## 路由配置与回退

分流页按服务器保存规则、默认出口和自定义出站，详见 [路由与出站](路由与出站.md)。首个路由/出站写操作会将中心数据升级至 schema 4，alpha.3 及更早程序不能直接打开；回到旧程序需要匹配的旧快照，先保留当前数据。升级脚本仍会在切换前保存私有恢复快照。仅撤回新程序二进制不能撤回数据格式。

geosite/geoip 由固定 MetaCubeX 官方仓库下载 `.srs` 文件，Agent 的 `routing-cache.db` 用于本机规则集缓存。分类首次应用和更新依赖 VPS 外网，新增分类错误或下载失败应查看 Agent 的配置任务；不要把保存成功当作代理出口已经连通。

## alpha.5 配置扩展

节点参数编辑、路由/出站变更和出站导入使用 schema 5。请使用匹配当前数据的程序；升级前私有快照仍由安装脚本保存。SS2022 改算法或主密钥时，需在编辑页确认轮换；订阅 token 保留，但受影响节点的客户端需要刷新订阅。

Reality 私钥、SS 主密钥和 HY2 混淆密码不通过状态接口返回；只有登录管理员显式读取密钥或导出出站链接时返回对应内容。普通编辑留空沿用，关闭混淆会清除该项。入站 Tag 修改由编译器同步内部路由引用。

## alpha.6 可靠性与设置

管理账号首次设置、后台改密和 CLI 重置均允许 8 位密码；备份口令独立，仍为 12–128 位。后台「管理入口」单独修改域名后的安全路径和管理端口，不包含面板域名迁移。

HTTPS、Telegram 与客户端预设分别保存。提交携带分区版本，冲突保留输入并提供最新脱敏设置；保存并加载/验证会先保存当前编辑。入口草稿校验不阻止其他分区保存。

带操作标识的创建请求与加密幂等回执原子提交；回执最多 256 项、有效期 24 小时，含注册码的结果不通过状态接口公开。首次此类写入使用 schema 6，alpha.5 及更早版本禁止打开；回退旧程序需匹配旧数据快照。

## alpha.7 在线备份与安全构建

登录代理来源隔离、三个组件的安全构建和扫描边界见 [安全构建与漏洞处置](安全构建与漏洞处置.md)。本轮不修改既有管理员密码、管理路径或端口，数据 schema 仍为 6。

管理脚本的 `backup 文件` 现在读取运行中 SQLite 的单个已提交快照，不再停止中心。数据库仍只有一个写入进程，不绕过写入锁；导出使用独立口令加密，可移机，不依赖原 `master.key`。文件以 0600 临时文件写入并原子替换，失败时不提前截断已有备份。当前文件上限 32 MiB，超限明确失败。

```sh
/opt/relaydeck/bin/relaydeck backup --online --data /var/lib/relaydeck/panel --file /secure-backups/panel.rdbak
/opt/relaydeck/bin/relaydeck verify-backup --file /secure-backups/panel.rdbak
```

口令从标准输入读取。自动化可传 `--password-file /secure-config/backup.pass`：必须是普通文件，禁止符号链接及组/其他用户权限，单行 12–128 字节。命令行里不传口令正文。备份口令和备份文件应分开保管；丢失口令不能解密。

`verify-backup` 只验证解密、结构与数据版本，不替换运行中的中心，也不更改授权代次；错误口令或损坏文件检查失败。它不能替代真实恢复演练。

恢复命令仍需停止目标中心；恢复会替换目标数据。请先在隔离目录/机器演练，确认用户名和订阅凭据保留、恢复代次更新、Agent 重新同步后才交付授权。当前便携备份包含中心持有的导入证书和凭据，不包含 Agent 身份、流量台账、节点本机 ACME 缓存及中心 Caddy 的自动证书缓存；完整 VPS 灾难恢复须另行备份或按已验证步骤重建这些资产。

计划任务、保留历史、离机复制与失败通知仍需完成，不能把本次在线导出功能称为已完成自动离机灾备。后续需落实 RPO/RTO 并完成整机丢失恢复验收。
