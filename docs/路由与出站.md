# 路由与出站

分流页先选择服务器，再使用「路由规则」「出站」「客户端分流」三个标签页。

## 三步配置

1. 在「出站」添加代理，填写名称、唯一标签和目标连接信息。支持 SOCKS5、HTTP/HTTPS、VLESS Reality、HY2、SS2022；已有内网落地会自动显示。
2. 在「路由规则」添加规则，填写备注、需要匹配的条件，选择直连、拒绝或刚添加的出站。可按公开入站节点、订阅缩小范围。
3. 保存后查看服务器配置版本。Agent 检查配置并应用，版本一致表示核心已接受配置；仍需实际连接来验证目标代理可用。

规则从上到下，首个命中生效。不同条件需要同时满足，同一条件中的多项任选其一。空条件需要明确勾选「全部流量」；普通规则不要用它代替目标域名。可以复制、开关及上移/下移规则。

域名每行一项：`domain:example.com` 包含子域名，`full:api.example.com` 精确匹配，另支持 `keyword:`、`regexp:` 和 `geosite:cn`。普通域名按包含子域名处理。目标 IP 支持地址、CIDR、`geoip:cn`、`geoip:private`。端口使用 `443,8000-9000`。来源条件中的 IP 指代理入站观察到的客户端来源。

协议条件依赖嗅探，添加此类规则会自动开启本台服务器嗅探。IP 规则用于域名目标时，可开启「匹配 IP 前解析域名」，使用 VPS 系统 DNS。

## 默认出口和内网落地

管理服务端口保护优先于用户规则，内部 SS2022 入站固定直出以防止回环。公开节点先匹配自定义规则，然后使用节点明确指定的内网落地；未指定落地则使用本台服务器默认出口。没有自定义设置时默认直连。

代理不可达会使相应连接失败，不自动回退直连。HTTP 出站只承载 TCP；HY2 出站的连续跳跃需要对端已配置相应 UDP 端口及防火墙转发。代理链中每个前置代理都需支持下一跳所用的传输：例如 HY2 使用 UDP，不能通过仅 TCP 的 HTTP 代理建立。

出站标签修改不会丢失路由引用。被规则、默认出口或代理链引用的出站不能删除；停用活跃引用需先调整对应规则。已保存密码或 UUID 留空沿用，状态接口与配置预览隐藏密钥。SOCKS/HTTP 清空用户名可移除认证。

## 地理规则与客户端规则

geosite/geoip 使用 [MetaCubeX 的 sing-box 规则集](https://github.com/MetaCubeX/meta-rules-dat/tree/sing/geo)，每日更新，本机缓存。首次应用需要访问该仓库且分类存在。使用 sing-box `.srs` 格式，不直接读取 Xray `.dat` 文件。

「客户端分流」用于 Clash Verge 的订阅策略组、DNS 和域名/IP 规则，更新后刷新客户端订阅。服务器路由在 VPS 生效；两者作用位置不同。Shadowrocket 当前提供节点 URI 订阅，尚未导出完整客户端规则。

字段组织参考 [3x-ui 路由页面](https://github.com/MHSanaei/3x-ui/tree/main/frontend/src/pages/xray/routing)、[出站页面](https://github.com/MHSanaei/3x-ui/tree/main/frontend/src/pages/xray/outbounds)；配置由 RelayDeck 独立编译为 [sing-box 路由](https://sing-box.sagernet.org/configuration/route/rule/)。当前没有 Xray 全量出站、负载均衡、WARP 和原始 JSON 导入/编辑功能。

## alpha.5 出站导入与导出

在「出站 → 导入出站」粘贴单条、多行分享链接、Base64 URI 集合，或读取链接文本文件。解析后选择有效项；错误项显示原因，重复项默认不选。支持跳过、覆盖保留引用或新建；提交前列表变化需重新解析。未知查询参数明确拒绝。当前不抓取订阅 URL，不接受 JSON/YAML 配置文件，来源管理在后续批次。

当前导入支持 VLESS Reality TCP/RAW、HY2、SS2022 AES-128/256、SOCKS5、HTTP/HTTPS；其他 VLESS 安全/传输、SS 插件或未适配参数会报告失败。覆盖匹配依据相同连接或自动生成的 Tag；无法可靠识别同一记录时应手工核对，不按列表位置覆盖。新出站不自动更改已有默认出口和路由。

单行的「分享 / 导出」可复制或下载链接，工具栏可导出本台所有自定义出站链接。分享链接包含认证；代理链不能写入普通分享 URI，导出会明确说明。SS network 属于导入扩展，其他客户端未必识别。

节点 / 入站现在可直接选择自定义出站；“继承服务器默认出口”和“明确直连”分别保存，仍服从前面的路由规则。HY2 使用 UDP，禁止选仅 TCP 的 HTTP 出站作为前置代理。
