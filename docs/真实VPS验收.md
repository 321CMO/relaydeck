## 实机发现并修复

1. Caddy 默认 HTTP/3 会占用 UDP 443。中心配置与首次安装模板显式使用 HTTP/1.1、HTTP/2，保留 UDP 443 给 HY2，加入官方 Caddy 适配结果回归检查。
2. 恢复旧备份时，Agent 生效版本可能高于中心旧版本而持续被拒绝。恢复生成新代次、清零旧回执，并按代次隔离 Agent 配置目录；新代次实际应用后才发布订阅。恢复后的数据使用 schema 2，旧程序拒绝打开，避免静默忽略代次。
3. 已保留身份的 Agent 重装不应再索取过期安装码。CLI 先检查身份并验证中心及服务器归属，再决定是否读取一次性安装码。
4. 恢复的 HTTPS 加载状态失效，需重新加载验证，不能沿用另一实例的状态。

HTTP 回显目标在测试中补齐 Content-Length；不把测试目标自身关闭连接导致的问题归为协议缺陷。

- arm64 真机、其他发行版、长期运行、弱网丢包、真实证书临期续期。
- Shadowrocket 真机分流与端口跳跃、Clash Verge 图形界面操作。
- 真实 TG Bot 的绑定、投递和限流联调；目前仍只有已实现的手动 Chat ID 通道。
- 流量额度限制、完整迁移和正式稳定版发布，继续属于未完成范围。

测试规格、备份、登录资料与故障注入包均保留在私有测试目录，不是正式发布资产。公开测试代码默认跳过外部 VPS 测试，只有显式提供私有规格文件才会连接测试主机。

- 浏览器直接打开原订阅地址，显示实际用量、最后上报、到期和三条授权节点；复制、客户端自动格式识别、用量响应头、手机布局及用户隔离通过。

- 用单文件脚本从 alpha.3 升级至 alpha.4，中心、Agent、Caddy 正常；保留原管理端口、安全路径、管理员密码、订阅地址和累计用量。升级后真实 Agent 自动应用新编译版本。

- 为订阅 A 配置测试目的端口的 SOCKS5 出站，出口仅监听 VPS 回环地址。跨公网导入真实订阅，A/B 的 Reality、HY2、SS2022 均通过 TCP/UDP，A 的流量确实进入该出口；HY2 固定端口和定时跳跃通过，管理端口保护通过。
