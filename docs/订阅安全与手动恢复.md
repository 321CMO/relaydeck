# alpha.9：订阅安全与手动恢复

## 订阅泄露后的操作

在「订阅 → 安全 / 轮换」选择要撤销的范围。重置订阅地址会立即使旧订阅与个人网页返回 404，但不会更换已经导入客户端的节点认证。选择节点认证会更新该订阅在所选节点的 UUID、HY2 密码或 SS2022 用户密钥；服务端主密钥、其他订阅和未选节点不变。

先生成影响预览，再勾选确认。配置或授权发生变更时，旧预览不能提交，必须重新核对。请求要求幂等键；响应丢失后重试不会再次轮换。认证变更会发布入口配置，同一入口的客户端可能短暂重连；Agent 确认生效前不交付新授权。成功后重新打开交付页获取最新地址，不从旧回执缓存地址。

## 后台人工备份导出 / 导入

在「设置」下载独立口令加密的备份，保管文件和口令。导入选择备份、输入备份口令，先查看对象数量和替换范围；再输入当前管理员密码并明确确认。预览不改业务数据，10 分钟后失效。预览后业务配置被修改则拒绝覆盖，Agent 心跳和统计更新不造成误冲突。

网页恢复替换服务器、节点、订阅、路由、出站和 TG 设置，**保留当前管理员账号/密码与当前域名、管理端口、安全路径及面板 HTTPS 配置**。完整搬迁账号和入口使用终端隔离恢复。恢复撤销全部管理会话，必须重新登录；Agent 使用新同步代次，重新确认应用前不交付恢复的节点授权。

导入会回退至备份时的订阅和认证，可能重新启用后来撤销的旧地址；表单必须明确确认。备份不包括完整操作系统、Agent 本机身份/流量台账、外部 DNS、全部证书缓存。不是整机镜像；新机器仍需安装、恢复证书资产及登记或重装 Agent。

每次网页导入提交前，中心在数据目录 `web-restore-checkpoints/` 保存当前状态的独立加密备份和私有口令文件，目录 0700、文件 0600，最多保留 3 对。创建失败则取消导入。同机恢复点只用于误导入后的终端回退；主机丢失后仍需你手动下载保存的备份。按照项目范围不提供定时或离机备份。

网页支持加密备份文件最多 32 MiB，当前限制 200 服务器 / 2000 节点 / 1000 订阅 / 5000 路由 / 2000 出站；这是输入资源上限，不是商用容量承诺。不完整引用、非法节点配置或已失效导入证书会拒绝网页恢复，应先终端隔离恢复检查。

## 审计与版本兼容

设置页可分页查看最近 2000 条操作审计，包含管理员、来源、时间、对象 ID、动作和字段名；不存字段值、密码、密钥或订阅 URL。审计与相关业务写入同事务保存，轮换重试不重复记账。它不是独立不可篡改日志，也不覆盖所有登录和 Agent 生命周期事件。

首次带审计写入将数据 Schema 升到 7。alpha.8 及更旧程序会拒绝读取，不应直接保留新数据降级。升级失败由安装器恢复升级前程序和数据；手动降级应使用对应版本的升级前备份，不能以删除字段绕过版本检查。
